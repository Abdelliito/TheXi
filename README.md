# TheXI

A World Cup 2026 football tracker built with React, Vite, Tailwind CSS, Axios, and React Query.

## Features

- Fixtures
- Teams
- Standings
- Knockout Bracket
- Match Details
- Team Details

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- TanStack React Query

## Installation

npm install
npm run dev

## Build

npm run build
